# Terminology

[![中文](https://img.shields.io/badge/Language-%E4%B8%AD%E6%96%87-0A66C2)](zh/terminology.md)

This page maintains recurring cross-page terminology in the `knowledge/` corpus.

Default rules:

- Main prose in the root corpus prefers English.
- Formal titles such as paper titles, repository names, course names, and talk titles should remain in their original form.
- Unless there is a clear reason not to, recurring cross-page terms should follow the default forms recorded here rather than switching among near-synonyms.
- Prefer flat declarative sentences. Avoid leaning too heavily on repeated "not ... but ..." contrast constructions.

## Maintenance Notes

- When a new cross-page term appears, add it here first and then normalize the prose.
- If an English word appears only inside a formal title, it does not need its own terminology entry.
- If one Chinese term carries different meanings on different pages, make the boundary explicit in the notes column instead of forcing a merge.
