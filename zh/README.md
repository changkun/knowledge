# 知识库

[![English](https://img.shields.io/badge/Language-English-111827)](../README.md)

> 注：公开出处统一使用网站链接；未发布草稿仅保留题名，不使用仓库内部路径。

本库按主题整理欧长坤长期稳定的知识领域、问题意识与写作取向。重点放在持续出现的方法、判断和边界，不放在经历清单。材料来源也不限于博客正文，同时纳入教育、研究、工作、教学与开源经历，以及那些本身就以课程、论文工件、教程、翻译、阅读清单和知识基础设施形态存在的 GitHub 仓库。

它更接近一张分层展开的知识地图：底层是数学、系统与语言观，中层是研究主题与人机问题，上层是教学、开源与写作等公共输出，外围则是跨文化生活与长尾写作提供的背景和边界。

## 参考范围

- 参考材料覆盖 2009 至 2026 年的公开文章、公开笔记、专题页、教程页、项目页，以及少量未发布草稿。
- 正式教育、研究、工作、教学与开源经历用于校准时间线、专业身份与领域边界。
- 研究材料主要参考公开研究主页、论文、学位论文、答辩与讲稿；未发布研究计划稿只用于判断近年的问题推进方向，不直接当作既成结论。
- GitHub 上的公开仓库也被当作正文材料来读，尤其是课程仓库、研究工件、书籍与教程仓库、翻译清单、阅读清单与论文模板这类高知识密度仓库。
- 不包含图片、静态资源、标签页或站点配置文件这类非正文材料。
- 较早期的 QQ 空间导入文本中有较多重复稿和短札；这里主要依据内容完整、能稳定反映问题意识的文本。

## 总体画像

- 起点是数学兴趣，尤其偏向集合论、公理化、序关系、测度、证明结构与“定义为什么这样设”。
- 进入计算机之后，长期关注系统为何成立，不局限于单一框架，包括运行时、内核、内存、性能测量、源码设计、基础设施与工程约束。
- 对 AI 的理解同时会从统计学习理论、人机交互、人肉计算、社会系统、主体性和自指问题来观察，不建立在单纯的模型乐观主义上。
- 正式研究主线围绕“人怎样进入决策、优化与反馈闭环”展开，应用域横跨行为理解、人在环优化、自适应 VR/AR、众包与机器学习结合，以及智能体监督等案例。
- 一些高投入案例域会在研究、教学与工程中反复出现，但它们更适合作为方法和问题意识的承载体，本身不构成唯一中心。
- 这些兴趣后来分别落实为人机交互与人机闭环研究、LMU 教学、跨平台产品开发、企业 AI 平台与收益优化系统。
- 近年的公开笔记表明，AI 关注点已经推进到智能体工作流、人在环、责任链、确认疲劳、偏好建模与自指机制。
- 这些知识既通过长文表达，也长期通过课程仓库、教程书、研究工件、项目归档和交互原型来表达。
- 开源与公共输出长期构成职业身份的一部分：Go 与 Fyne 社区、`golang.design`、TalkGo、翻译与公共教程构成了另一条稳定主线。
- 从成都到慕尼黑的长期迁移，以及中文、英文、德语之间的切换，使后期写作逐渐带上跨文化和制度比较视角。
- 近年的文化重心也从工程上的“怎么做”进一步转向“为什么做、为谁做、这种结构如何长期稳定”。

## 稳定的方法论

- 公理化：追问系统的最小前提、对象的构造方式以及定义背后的必要性。
- 结构化：偏好从整体结构、约束条件和边界出发，不满足于只罗列经验技巧。
- 机制优先：面对性能、理论或工程问题时，倾向先追到底层机制，再谈表层实践。
- 深度优先：随着时间推移，越来越强调长期实践形成的深度，避免广度式炫技。
- 交叉视角：数学、工程、社会选择、哲学与个人经验常被放在同一问题链条里思考。

## 一条清晰的演化线

- 2009-2013：高强度数学自学，随后进入 C/C++、算法、OpenCV、Linux 与基础课程世界。
- 2014-2018：从计算机视觉与机器学习进一步转向统计学习理论、人机交互、人肉计算与系统化写作，并在德国完成人机交互与研究训练的阶段转轨。
- 2018-2023：LMU 的研究与教学阶段，使网页行为研究、人机闭环、人在环优化、自适应 VR/AR、课程设计、案例域实践、Go 运行时与公共输出并行推进。
- 2022-2026：进入企业工程与 AI 平台阶段，在收益优化、智能体工作流、知识管理、偏好建模与组织级 AI 转型中继续把研究兴趣落到生产系统。

按上面的四层去看，这条演化线会更清楚：先形成基础层，再汇入研究层，再不断长出输出层，而背景层始终在外围调整重心。

## 本库关注什么

- 关注长期反复出现的知识主干，不写“会过哪些技术”的流水账。
- 关注跨越多年仍然稳定存在的问题，而不追随短期热点判断。
- 试图从长期写作、项目与正式经历中还原思考习惯、领域边界与文化取向，不做自我包装。
