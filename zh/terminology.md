# 术语对照

[![English](https://img.shields.io/badge/Language-English-111827)](../terminology.md)

本页用于维护 `knowledge/` 语料中跨页面重复出现的术语。

默认规则：

- 正文优先使用中文表述。
- 论文名、仓库名、课程名、讲稿题名等正式标题保持原文。
- 如无特殊需要，跨页面复现的术语应尽量使用这里的默认写法，不在正文中频繁切换同义表达。
- 尽量少用“不是……而是……”这类强对照句，优先改写为更平直的陈述句。

## 研究与人机

| 中文 | 英文 / 原文 | 说明 |
| --- | --- | --- |
| 人在环 | human in the loop | 正文中的默认写法。 |
| 智能在环 | intelligence in the loop | 与“人在环”配套出现时保留原英文对应。 |
| 人机闭环 | human-machine loop | 用于概括人进入反馈回路后的系统关系。 |
| 回路失效 | loop failure / human-AI loop failure | 区别于单点错误，强调闭环中的结构性失败。 |
| 自我模型 | self-model | 多用于主体性与元认知语境。 |
| 网页浏览行为 | web browsing behavior | 除论文标题外，正文统一用中文。 |
| 前瞻记忆 | prospective memory | 用于描述任务保持与未来意图提醒。 |
| 上下文切换 | context switching | 用于行为研究与认知负担语境。 |
| 注意状态 | attention state | 如需区分，可写“内外注意状态”。 |
| 意图保持 | intention retention | 常见于短视频和任务保持语境。 |
| 意见测量界面 | opinion measurement interface | 指塑造意见表达的界面结构。 |
| 权衡 | trade-off | 正文不用 `trade-off`。 |
| 责任链 | responsibility chain | 与监督、问责和治理语境相关。 |
| 众包与机器学习结合 | crowd + machine learning | 用于描述 crowd 与 machine learning 的组合问题。 |
| 视觉复杂度自适应 | visual complexity adaptation | 自适应 VR/AR 研究中的具体方向。 |
| 内外注意平衡 | internal/external attention balance | 指 internal / external attention 的平衡。 |
| 混合现实视觉搜索 | mixed reality visual search | 混合现实研究中的具体任务。 |
| 混合现实输入 | mixed reality typing | 统一对应 mixed reality typing。 |
| VR 运动游戏 | VR exergaming | 保持简洁，不再混用英文。 |
| 眼动追踪 | eye tracking | 正文中的默认写法。 |
| 注视相关电位 | fixation-related potentials | 用于生理与认知信号语境。 |
| 建构性偏好 | constructed preference | 用于偏好研究语境。 |
| 身份建构 | identity construction | 用于主体性与社会理论语境。 |
| 帕累托前沿 | Pareto frontier | 默认中文写法。 |

## 输出、写作与材料

| 中文 | 英文 / 原文 | 说明 |
| --- | --- | --- |
| 公共输出 | public-facing output | 指面向他人的长期技术与知识输出。 |
| 公共材料 | public-facing materials | 多用于课程、教程和可传播材料。 |
| 公共资产 | public assets | 多用于仓库、模板、站点和长期可复用成果。 |
| 知识基础设施 | knowledge infrastructure | 指站点、模板、流程、服务等支撑层。 |
| 仓库式写作 | repository-based writing | 指以仓库为主要组织单元的写作方式。 |
| 课程讲义 | lecture notes | 除正式课程名外，正文统一用中文。 |
| 论文源码 | thesis source | 指论文源文件，不限于代码。 |
| 数据集 | dataset | 正文统一用中文。 |
| 分析脚本 | analysis script | 正文统一用中文。 |
| 课件 | slides | 教学材料语境中的默认写法。 |

## 维护说明

- 新增跨页面术语时，优先补充本页，再回头统一正文写法。
- 如果某个英文词只在正式标题中出现，不必为它单独建立术语条目。
- 如果一个中文词在不同页面承担不同含义，应在“说明”列中明确边界，避免强行合并。
